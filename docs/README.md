# Документация SOFIZAR

| Раздел | Что внутри |
|---|---|
| [HLD](hld/README.md) | Архитектура верхнего уровня: контекст, контейнеры, потоки данных, окружения, нефункциональные требования |
| [LLD](lld/README.md) | Детальный дизайн: модель данных, API, интеграции |
| [ADR](adr/README.md) | Журнал архитектурных решений |
| [client/](client/) | Документы для заказчика: что нужно от SOFIZAR, дорожная карта |
| [CONTRIBUTING](../CONTRIBUTING.md) | Процесс: задачи, ветки, коммиты, Definition of Done |

## Когда что обновлять

- Поменялась схема БД или API → **LLD** в том же PR.
- Выбрали технологию / подход, который дорого менять → **ADR**.
- Появился новый сервис, внешняя система или поток данных → **HLD**.
