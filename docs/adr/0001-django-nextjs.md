# ADR-0001: Django + Next.js вместо 1С-Битрикс

- **Статус:** Принято
- **Дата:** 2026-11-10

## Контекст

Нужен интернет-магазин ювелирных изделий с каталогом, корзиной, личным кабинетом, админ-панелью, тремя языками, двусторонним обменом с 1С, интеграциями с Bitrix24 и UZQR. Ключевой канал продаж — поисковая выдача, поэтому SEO критично. Команда пишет на Python.

## Решение

- **Бэкенд:** Django + Django REST Framework. Django Admin используется как административная панель.
- **Фронтенд:** Next.js (App Router, TypeScript) с серверным рендерингом и ISR.
- Связь между ними — REST API `/api/v1/`.

## Альтернативы

| Вариант | Плюсы | Минусы |
|---|---|---|
| **1С-Битрикс «Управление сайтом»** | Готовый модуль обмена с 1С, нативная связка с Bitrix24 | PHP (не стек команды), платная лицензия, тяжёлая кастомизация дизайна |
| **Только Django (шаблоны + HTMX)** | Один язык, меньше движущихся частей | Сложнее делать анимированный интерфейс из концепта |
| **FastAPI + Next.js** | Быстрый, современный API | Нет готовой админки, ORM и миграций уровня Django — больше ручной работы |
| **Django + Next.js** ✅ | Готовая админка, зрелая ORM, Python; лучший в классе SSR/ISR для SEO | Два приложения вместо одного |

## Последствия

- Админка из коробки экономит недели работы.
- Обмен с 1С придётся реализовать самим (см. будущий ADR по формату обмена).
- Нужен CORS/прокси между фронтендом и API; два Docker-образа.
