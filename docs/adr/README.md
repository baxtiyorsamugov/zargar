# ADR — Architecture Decision Records

Каждое значимое архитектурное решение фиксируется отдельным файлом: что решили, почему, какие были альтернативы и какие последствия.

## Правила

- Новый ADR — копия [`template.md`](template.md) с номером `NNNN-короткое-название.md`.
- ADR не редактируют задним числом. Если решение меняется — пишут новый ADR со статусом `Принято`, а старому ставят `Заменён ADR-NNNN`.
- ADR добавляется в том же Pull Request, где реализуется решение.

## Статусы

`Предложено` → `Принято` → (`Устарел` | `Заменён ADR-NNNN`)
