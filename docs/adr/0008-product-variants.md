# ADR-0008: Товар + варианты по размеру

- **Статус:** Принято
- **Дата:** 2026-11-10

## Контекст

Одно ювелирное изделие (например, кольцо) выпускается в нескольких размерах. У каждого размера может быть свой вес, своя цена (цена золотых изделий часто зависит от веса) и свой остаток. В 1С это обычно номенклатура с характеристиками.

## Решение

- `Product` — изделие: название, описание, металл, проба, вставки, фото, категория.
- `ProductVariant` — конкретный размер: артикул варианта, размер, вес, цена, старая цена, остаток, `external_id` из 1С.
- Изделие без размеров (например, подвеска) имеет один вариант с пустым размером.
- Заказ ссылается на **вариант**, а не на изделие.

## Альтернативы

| Вариант | Плюсы | Минусы |
|---|---|---|
| Одна модель `Product`, размеры списком | Проще | Нельзя хранить отдельные цену, вес и остаток для размера |
| EAV (универсальные атрибуты) | Гибко | Медленно, сложно фильтровать |
| **Product + ProductVariant** ✅ | Совпадает с моделью 1С, честные остатки по размерам | Чуть сложнее админка |

## Последствия

- Фильтр по цене и наличию работает по вариантам.
- Цена «от …» в каталоге — минимальная цена среди доступных вариантов.
