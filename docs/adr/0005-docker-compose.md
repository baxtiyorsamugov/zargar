# ADR-0005: Docker Compose для локального окружения

- **Статус:** Принято
- **Дата:** 2026-11-10

## Контекст

Проект состоит из 5 сервисов (frontend, backend, worker, PostgreSQL, Redis). Каждый разработчик должен поднимать одинаковое окружение одной командой.

## Решение

`docker-compose.yml` в корне репозитория поднимает все сервисы для разработки с горячей перезагрузкой кода. Конфигурация — через `.env` (шаблон `.env.example`). Отдельный production-compose появится вместе с сервером.

## Альтернативы

| Вариант | Плюсы | Минусы |
|---|---|---|
| Ставить всё локально | Без Docker | У всех разные версии, долгая настройка |
| Kubernetes | Масштабирование | Избыточно для проекта такого размера |
| **Docker Compose** ✅ | Одна команда, одинаково у всех | Нужен установленный Docker |

## Последствия

- Те же Docker-образы собираются в CI, что исключает «у меня работает».
