# ADR-0004: Мультиязычность через префиксы `/uz/ /ru/ /en/`

- **Статус:** Принято
- **Дата:** 2026-11-10

## Контекст

Сайт на трёх языках. Для SEO каждая языковая версия должна иметь собственный URL, иначе поисковик индексирует только один язык.

## Решение

- **URL:** каждая страница доступна по адресу с префиксом языка: `/uz/...`, `/ru/...`, `/en/...`. Между версиями ставятся ссылки `hreflang`.
- **Переводы контента в БД:** django-modeltranslation. Создаются поля `name_uz`, `name_ru`, `name_en` в тех же таблицах.
- **API:** отдаёт контент на языке из заголовка `Accept-Language`.
- **Язык по умолчанию:** пока `ru`, окончательно уточняется у заказчика.

## Альтернативы

| Вариант | Плюсы | Минусы |
|---|---|---|
| Язык в cookie, один URL | Просто | Поисковики видят только один язык |
| Поддомены `uz.sofizar.uz` | Чёткое разделение | Сложнее SSL, деплой, аналитика |
| django-parler (отдельные таблицы переводов) | Гибко | Сложнее запросы и фильтрация |
| **Префиксы + modeltranslation** ✅ | Стандарт для SEO, простые запросы | Добавление языка требует миграции |

## Последствия

- Добавление четвёртого языка — миграция БД. Это приемлемо.
- В sitemap выводятся все три версии каждой страницы.
