# ADR-0002: PostgreSQL как основная БД

- **Статус:** Принято
- **Дата:** 2026-11-10

## Контекст

Нужна надёжная реляционная БД для каталога, заказов и клиентов, с транзакциями (оплата, остатки) и хорошей поддержкой в Django.

## Решение

PostgreSQL 16.

## Альтернативы

| Вариант | Плюсы | Минусы |
|---|---|---|
| MySQL / MariaDB | Распространён | Слабее поддержка JSON и полнотекстового поиска в Django |
| SQLite | Ноль настройки | Не подходит для конкурентной записи в продакшене |
| **PostgreSQL** ✅ | Транзакции, JSONB, полнотекстовый поиск, `django.contrib.postgres` | — |

## Последствия

- Полнотекстовый поиск по каталогу можно сделать средствами PostgreSQL без отдельного поискового движка на старте.
- Тесты в CI запускаются на настоящем PostgreSQL, а не на SQLite.
