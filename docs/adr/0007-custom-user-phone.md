# ADR-0007: Своя модель пользователя с входом по телефону

- **Статус:** Принято
- **Дата:** 2026-11-10

## Контекст

По КП клиент входит в личный кабинет **по номеру телефона**. В Django модель пользователя нужно определить до первой миграции: заменить её позже очень дорого.

## Решение

Своя модель `accounts.User`, где логином служит телефон (`phone`, уникальный, формат E.164: `+998XXXXXXXXX`). Email необязателен. Сотрудники входят в админку по тому же телефону и паролю. Покупатели в будущем — по SMS-коду.

## Альтернативы

| Вариант | Плюсы | Минусы |
|---|---|---|
| Стандартный `auth.User` + профиль с телефоном | Ничего не писать | Логин по username, неудобные запросы, менять потом — сложная миграция |
| **Своя модель с `phone`** ✅ | Телефон — естественный ключ клиента в Узбекистане, совпадает с CRM | Нужен свой менеджер пользователей |

## Последствия

- Телефон нормализуется к одному формату, иначе появятся дубли клиентов в Bitrix24.
- Вход по SMS-коду — отдельная задача после выбора SMS-провайдера.
