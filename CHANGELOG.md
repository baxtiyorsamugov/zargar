# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [Не выпущено]

### Изменено — дизайн-система v1

- Витрина в утверждаемом дизайне: шрифт Gilroy, палитра Yuksalish (сине-бирюзовый градиент, мятный фон, золото как акцент), линейные иконки.
- Новая шапка (верхняя полоса, поиск, кабинет/избранное/корзина со счётчиками, меню категорий) и подвал.
- Главная: баннер, популярные категории с фото, новинки, коллекция, преимущества, блок «Наш завод». Тексты — в словаре `ui` на UZ / RU / EN.
- Карточка товара в сетке: скидка, металл с цветом и пробой, цена «от».
- `seed_demo` прикрепляет демо-фото к изделиям по категории.
- Шрифты Gilroy (коммерческая лицензия) не хранятся в git: `frontend/public/fonts/README.md`.

### Добавлено — этап 03

- Корзина в браузере с проверкой цен и наличия на сервере (ADR-0009), выбор размера на карточке товара.
- Оформление заказа гостем и залогиненным пользователем, страница «Спасибо за заказ».
- Вход в личный кабинет по SMS-коду (ADR-0010), профиль, история заказов. Гостевые заказы привязываются к аккаунту после подтверждения телефона.
- Избранное, поиск в шапке, фильтры каталога (металл, цена, наличие, сортировка) и пагинация.
- SEO: служебные страницы и выдача с фильтрами закрыты от индексации, один адрес без слеша на конце.
- API: `/auth/*`, `/cart/`, `/orders/`, фильтр `slugs`. Celery-задача `order_created`.

### Добавлено — каркас

- Документация: HLD, ADR 0001–0008, LLD модели данных, процесс работы (CONTRIBUTING).
- Шаблоны Issues (задача, баг, ADR) и Pull Request.
- Каркас: Django + DRF (backend), Next.js (frontend), Celery, PostgreSQL, Redis в Docker Compose.
- CI на GitHub Actions: линтеры, тесты, сборка.
- Модели каталога и заказов, админ-панель, API каталога с фильтрами.
- Витрина на Next.js: главная, каталог с ЧПУ категорий, карточка товара, hreflang, Schema.org Product, sitemap.xml, robots.txt.
- Команда `seed_demo` — 12 демо-изделий на трёх языках.
