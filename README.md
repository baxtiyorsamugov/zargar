# SOFIZAR

Сайт ювелирной компании SOFIZAR.

## Фронтенд

`frontend/` — статический прототип главной страницы (HTML + CSS + JS без сборки):

- `index.html` — разметка
- `assets/css/main.css` — дизайн-токены (цвета, шрифт Gilroy, шкала размеров), светлая и тёмная тема
- `assets/js/main.js` — каталог, фильтры, избранное, бронь в магазине (данные пока примерные, позже из API ← 1С)
- `assets/fonts/` — сюда кладём лицензионные файлы Gilroy (см. README в папке)

Открыть локально: `python3 -m http.server -d frontend 8000` → http://localhost:8000
